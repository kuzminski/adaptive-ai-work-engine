# Example 3 — To-do list web page (HTML/JavaScript, no server)

Useful when you want to see a visible result quickly: open `index.html` from
the result folder in your browser after the Human Gate.

**Goal (Cel)**

> Mała strona HTML/JavaScript z listą zadań do zrobienia, działająca bez serwera.
> *(A small HTML/JavaScript to-do list page that works without a server.)*

**First iteration (Pierwsza iteracja)**

> Strona index.html z dodawaniem i usuwaniem zadań zapisywanych w localStorage.

**Direction (Kierunek)**

```
- filtrowanie: wszystkie / zrobione / do zrobienia
- prosty, czytelny wygląd
- eksport listy do pliku JSON
```
