AAW — Adaptive AI Work Engine (Windows x64) — szybki start
==========================================================

Pobierz:  https://github.com/kuzminski/adaptive-ai-work-engine/releases/latest
          (plik AAW-Windows-x64.zip w sekcji „Assets”)
Nie pobieraj „Source code (zip)” — to kod źródłowy, nie aplikacja.

Wymagane osobno, poza AAW (AAW ich nie instaluje i nie przechowuje haseł):
  * Git for Windows — https://git-scm.com/downloads
  * co najmniej jedno CLI AI, zainstalowane i zalogowane na Twoim koncie:
      Claude CLI (Claude Code) — logowanie: w terminalu wpisz  claude
      Codex CLI                — logowanie: w terminalu wpisz  codex login
      Gemini CLI (opcjonalnie) — logowanie: w terminalu wpisz  gemini  (konto Google)
Python, kompilacja ani terminal nie są potrzebne do uruchomienia samego AAW.

1. Rozpakuj AAW-Windows-x64.zip: prawy przycisk → „Wyodrębnij wszystkie…” → „Wyodrębnij”.
   Nie uruchamiaj AAW.exe z podglądu ZIP bez rozpakowania.
2. W rozpakowanym miejscu jest jeden folder: AAW. Otwórz go. W środku:
     AAW.exe            ← aplikacja (Eksplorator może pokazać ją jako „AAW”, typ: Aplikacja)
     SZYBKI_START.txt   ← ten plik
     QUICK_START.md, README.md, CHANGELOG.md, VERSION.txt, LICENSE
     EXAMPLES           ← przykładowe zadania
     _internal          ← pliki aplikacji, nie zmieniaj
3. Kliknij dwukrotnie AAW.exe. Aplikacja otworzy się w przeglądarce (adres lokalny 127.0.0.1).
   Jeśli Windows pokaże „System Windows ochronił ten komputer”: Więcej informacji → Uruchom mimo to
   (plik nie jest jeszcze podpisany cyfrowo).
4. Ekran powitalny → „Zaczynamy”. Kreator 7 kroków:
   projekt (wskaż folder swojego projektu Git) → narzędzia AI (AAW sam wykryje Claude/Codex/Gemini)
   → modele → cel → pierwsza iteracja → kierunek → START.

AAW pracuje w izolowanej kopii projektu, nigdy nie robi merge ani push;
na końcu każdego zadania czeka na Twoją decyzję (Human Gate).
STOP SAFELY / STOP NOW / RESUME — na stronie zadania; przerwane zadania widać na Home.

Dane (zadania, dowody, kopie robocze, logi): %LOCALAPPDATA%\AAW
Zamykanie: Ustawienia → Zamknij AAW (trwające zadania pracują dalej w tle).
Więcej (w tym samym folderze co AAW.exe): QUICK_START.md, README.md, CHANGELOG.md, folder EXAMPLES
