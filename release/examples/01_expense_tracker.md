# Example 1 — Expense tracker (Python, new or almost empty repo)

Good first task: small, clear, easy to verify. The same example is available in
the app under step 4 („Przykłady").

**Goal (Cel)**

> Prosta aplikacja w Pythonie do śledzenia wydatków: dodawanie wydatków, lista i eksport do CSV.
> *(A simple Python app to track expenses: add expenses, list them, export to CSV.)*

**First iteration (Pierwsza iteracja)**

> Model danych wydatku (kwota, kategoria, data, opis) i zapis/odczyt z pliku JSON, z testami jednostkowymi.

**Direction (Kierunek)** — broad, one per line

```
- polecenia w terminalu: dodaj, lista, usuń
- eksport do CSV
- podsumowanie miesięczne
```

Recommended levels: defaults (★). Expect 3–4 iterations, then the Human Gate.
