AAW — Adaptive AI Work Engine (portable) — szybki start
=======================================================

Wymagane osobno, poza AAW (AAW ich nie instaluje i nie przechowuje haseł):
  * Git for Windows — https://git-scm.com/downloads
  * co najmniej jedno CLI AI, zainstalowane i zalogowane na Twoim koncie:
      Claude CLI (Claude Code) — logowanie: w terminalu wpisz  claude
      Codex CLI                — logowanie: w terminalu wpisz  codex login

1. Rozpakuj AAW-Windows-x64.zip (prawy przycisk → Wyodrębnij wszystkie…).
2. Uruchom AAW\AAW.exe. Aplikacja otworzy się w przeglądarce (adres lokalny 127.0.0.1).
   Jeśli Windows pokaże „System Windows ochronił ten komputer”: Więcej informacji → Uruchom mimo to
   (plik nie jest jeszcze podpisany cyfrowo).
3. Ekran powitalny → „Zaczynamy”. Kreator 7 kroków:
   projekt → narzędzia AI → modele → cel → pierwsza iteracja → kierunek → START.

AAW pracuje w izolowanej kopii projektu, nigdy nie robi merge ani push;
na końcu każdego zadania czeka na Twoją decyzję (Human Gate).
STOP SAFELY / STOP NOW / RESUME — na stronie zadania; przerwane zadania widać na Home.

Dane (zadania, dowody, kopie robocze, logi): %LOCALAPPDATA%\AAW
Zamykanie: Ustawienia → Zamknij AAW (trwające zadania pracują dalej w tle).
Więcej: QUICK_START.md, README.md, CHANGELOG.md, EXAMPLES\
